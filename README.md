# 💱 Conversor de Moedas em Java

Projeto desenvolvido em **Java** para praticar fundamentos de programação, entrada de dados, estruturas condicionais e organização de lógica.

A aplicação permite converter valores em **Real (BRL)** para outras moedas por meio de um menu interativo no terminal.

---

## 🚀 Tecnologias utilizadas

- Java
- Scanner
- Estruturas condicionais
- Switch Case
- Formatação de valores com `String.format()`

---

## ⚙️ Funcionalidades

- Conversão de valores em BRL para outras moedas
- Menu interativo no terminal
- Validação de opções informadas pelo usuário
- Possibilidade de realizar múltiplas conversões
- Exibição formatada dos valores convertidos

## ▶️ Como executar o projeto

### Pré-requisito

- Java instalado

### Clone o repositório

~~~bash
git clone https://github.com/AdrianLimaaa/conversor-de-moedas-java.git
~~~

### Acesse a pasta

~~~bash
cd conversor-de-moedas-java
~~~

### Compile o projeto

~~~bash
javac ConversorMoedas.java
~~~

### Execute

~~~bash
java ConversorMoedas
~~~
