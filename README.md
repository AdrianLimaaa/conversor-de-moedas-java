Conversor de Moedas em Java

Descrição:
Este projeto implementa um conversor de moedas simples em Java, permitindo a conversão de valores de Reais (BRL) para Dólar (USD), Euro (EUR) e Bitcoin (BTC).

Tecnologias Utilizadas:

  - Java
  - Scanner (para entrada de dados do usuário)
  - Estruturas de Controle (if-else, switch-case)
  - String.format() (para formatar o valor com 6 casas decimais)

    
Funcionalidades

   - Entrada: O usuário insere o valor em Reais (BRL) e escolhe a moeda de destino (1: Dólar, 2: Euro, 3: Bitcoin).

   - Saída: O programa exibe o valor convertido, formatado com 6 casas decimais.

   - Menu Interativo: O usuário pode continuar convertendo valores ou sair do programa após cada conversão.

   - Validação de Entradas: O programa garante que as entradas do usuário sejam válidas para evitar erros.

Como Rodar o Projeto

  - Clone o repositório:
    
    git clone https://github.com/seu-usuario/conversor-de-moedas-java.git
    
  - Navegue até a pasta do projeto:
    
    cd conversor-de-moedas-java
    
  - Compile e execute o projeto: Se você tiver o Java instalado, pode compilar e rodar o programa com os seguintes comandos:

    Para compilar:
      javac ConversorMoedas.java

    Para rodar:
      java ConversorMoedas
